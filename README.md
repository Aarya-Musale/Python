# Python Learning Journey 🐍

Welcome to my Python repository! This repository documents my day-by-day progress and code snippets as I build and strengthen my core Python programming skills—ranging from basic syntax to advanced concepts.

---

## 📂 Repository Structure

Below is an overview of the topics and Jupyter Notebooks/scripts included in this repository:

Day / File Name	Description
Day 01 (Day01_Introduction_to_python.py)	Introduction to Python basics, syntax, and writing your first script.
Day 02 (Day02_DataTypes.ipynb)	Exploring fundamental Python data types (integers, floats, strings, booleans).
Day 03 (Day03_DataTypes_Continue.ipynb)	Continuation of data types and exploring built-in type operations.
Day 04 (Day04_List.ipynb)	Working with lists, indexing, slicing, and common list methods.
Day 05 (Day05_Tuple.ipynb)	Understanding tuples, immutability, and tuple methods.
Day 07 (Day07_Dictionary.ipynb)	Key-value pairs, dictionary manipulation, and traversal methods.
Day 08 (Day08_Typecasting.ipynb)	Converting data from one type to another explicitly and implicitly.
Day 09 (Day09_Conditional_Statements.ipynb)	Making decisions in code using if, elif, and else statements.
Day 10 (Day10_Iterative_for_loop.ipynb)	Automating repetitive tasks using for loops and range functions.
Day 11 (Day11_while_loop_and_Transfer_Statements.ipynb)	Implementing while loops alongside break, continue, and pass.
Day 12 (Day12_List_Comprehension_and_Fuction.ipynb)	Writing concise code with list comprehensions and defining basic functions.
Day 13 (Day13_Function_Arguements.ipynb)	Deep dive into positional, keyword, default, and variable-length arguments.
Day 14 (Day14_Return_Keyword.ipynb)	Returning values from functions and handling multiple outputs.
Day 15 (Day15_Lambda_Function.ipynb)	Creating anonymous/inline functions using lambda.
Day 16 (Day16_Modules.ipynb)	Importing built-in and custom modules to organize and reuse code.
Day 17 (Day17_Exception_Handling.ipynb)	Managing errors gracefully using try, except, else, and finally.

## 🚀 How to Run the Code

To run these files locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Aarya-Musale/Python.git](https://github.com/Aarya-Musale/Python.git)

```

2. **Navigate into the folder:**
```bash
CD Python

```


3. **Run Python scripts (`.py`):**
```bash
python Day01_Introduction_to_python.py

```


4. **Open Jupyter Notebooks (`.ipynb`):**
Make sure you have Jupyter installed (`pip install notebook`), then run:
```bash
jupyter notebook

```
